# Color and luminance masks — 0.13.0 (14)

Tested on the physical iPhone 17 Pro (Orange) and iPhone 18 Pro simulator. Native/simulator photo, encoded-video and rendered-editor checks passed. Pixel-reference tests cover hue wraparound, gray protection, soft color/brightness boundaries, inversion/strength, stable pre-local selection, guide accuracy, HDR normalization, persistence and original preservation. Export checks cover source-specific selection, guide exclusion, encoded SDR color/luminance masks and HDR highlight selection with headroom retained. Existing brush, gradient, color, crop, trim/audio and Log regressions also passed. Native video includes Standard, Apple Log and Log 2; simulator encoding uses Standard only.

The native rendered-editor diagnostic applied 180 updates while switching between Color/Luminance controls, toggling inversion/guide and testing undo deletion. It created no extra players; maximum observed main-actor interval was 36.1 ms including the requested 16 ms sleep. It drives model methods while rendering actual views, rather than automated finger gestures.

The final sustained native fixture check passed 7,200 requested updates over 130.6 seconds with four masks (brush, color, luminance and gradient), HDR 1080p playback, a 65-point LUT, scopes and split comparison. It recorded 4,426 render completions, 3,716 decoded frames, zero GPU errors, zero extra idle frames and zero scope jobs after hiding scopes. GPU submission-to-completion p95 was 19.46 ms; scope analysis p95 was 12.79 ms. Coalescing intentionally drops superseded preview updates; these counts are not an assertion of 60 fps or a presentation-frame-rate measurement.

Thermal state was fair (1) at both endpoints; the phone did not start nominal/cool. No temperature sensor or battery-energy benchmark was captured. This does not establish zero heat, all-day efficiency or performance on every device, complex RAW or 4K source. Fixtures are generated constant-color clips. Two earlier runs left the foreground and are retained as explicitly interrupted reports; they are not passing sustained tests.

The signed normal Release archive passed strict code-signature verification. Diagnostic hooks are Debug-only. Range selection evaluates the globally graded/framed image before local layers; HDR uses the normalized creative image before headroom restoration. Color/brightness masks evaluate each video frame but do not track objects, smooth coverage over time or use keyframes. Brush/gradient masks remain spatially fixed. Originals stay untouched.

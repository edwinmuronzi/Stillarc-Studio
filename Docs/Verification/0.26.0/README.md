The additional native general-processing report did not refresh within its bounded check and is excluded; native file-level privacy and full video regression reports are fresh 0.26 results.

Final UI cases passed for single and batch privacy choices, default-off location, explicit location/project-name opt-in, creating exports, changing options, retained choices and clearing identifying metadata. These are bounded fixture and regression checks, not a guarantee for every camera metadata namespace or a sustained thermal/battery measurement.

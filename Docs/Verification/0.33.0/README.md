# 0.33.0 (37) — Color Warp and delivery

Native iPhone 17 Pro feature checks passed for HSL center mapping, soft reach, gray neutrality, the 0°/360° seam, strength, premultiplied alpha, invalid-value/duplicate bounds, persistence, schema-5 presets, Color copy/reset isolation and color-LUT export. JPEG, PNG and 10-bit HLG HEIF exports retained the requested 1280×960 dimensions; PNG kept transparent edges and SDR preview/export color agreed. A cropped-size/quality pool delivery retained the grade and requested dimensions. The original source bytes were unchanged. Generated trimmed 2560×1440 video exported to 1280×720 with its audio track and duration preserved. Compact iPhone 13 mini simulator feature checks also passed.

Native full Studio and generated video regression suites passed, including existing HDR, masks, tracking and audio paths. Five UI tests passed: direct map drag and four-point limit; sliders/reset/Undo/Redo/reopen; delivery size/quality/retry; all/selected pool delivery; reference matching regression. A test variable shadowing XCTest and a Toggle selector were corrected in the test harness. The final map test passed. Actual UI screenshots are included; the bundled sample is illustrative.

The optimized native sustained preview requested 1,800 updates over 80.94 seconds including a 15-second idle check. It completed 1,799 renders through latest-state coalescing, with render-start-to-completion p95 26.74 ms, zero GPU failures and zero extra idle frames. The workload combined a 65³ LUT, Color Warp and reference-match strength, curves, wheels, mixer, texture and film effects. iOS thermal state stayed 0 (nominal). This is a bounded still-preview measurement, not touch-to-display latency, measured display FPS, energy consumption, surface temperature or an older physical-device guarantee.

The Release archive, code signature, privacy manifest and whitespace checks passed. No beta/store submission was performed. Defaults remain Original + Maximum; smaller delivery is explicit, PNG stays lossless, and preview limits never choose final export quality. Full-source grading precedes Lanczos downsizing. HEVC quality is a target bitrate choice; exact compression/file size depends on the content. Video Color Warp uses a first-kept-frame SDR proof; playback remains in the main editor. This is global color warping, not semantic object selection. Additional camera transforms, grade keyframes, portable project packages and an export queue remain future scope.

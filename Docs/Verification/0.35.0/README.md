# 0.35.0 (39) — Backup path fix, visual picker, all-library backups and export queue

The reported Invalid project asset path error was reproduced with aliased directories: FileManager enumerates canonical paths even when the root URL uses a symlink alias, so substring-by-character-count produced the wrong relative path. Both roots/files now resolve aliases and compare path components, retaining outside-folder/traversal checks. A read-only audit of the actual iPhone 17 Pro library found 1 project/4 assets: all 4 paths were rejected by the previous code and 0 after the fix. No original media or edits were changed by the audit.

Native backup tests passed exact photo/video bytes, current edits/masks/LUT/Color Warp, references/backgrounds, saved versions/ratings, damaged/truncated/traversal/future-file rejection and mid-stream cancellation. A symlink-root library of 21 projects backed up and restored all 21 projects across two numbered parts. Back up all is not silently limited to the first 20 items; each independently restorable part retains the existing format limits.

Native queue tests passed explicit start, source-edit snapshots, serial photo/video delivery, reordering, cancellation/retry, completed-file persistence, interrupted-process recovery to Waiting, missing-source errors, output removal and pause/restart timing/geometry. The native core regression passed. Queue output remains on the shared rendering/export path, including metadata policy, alpha/HDR and source timing; no preview/rendering stage was added.

Five distinct UI workflows passed across initial successful cases and targeted retests: Back up all/thumbnails, single queue delivery, pool delivery, selected-backup/restore and picker/selection cancellation. Thumbnails use the existing bounded 160px cache and whole-row selection targets. Interrupted jobs restart at job boundaries; completed deliveries persist. Keep source projects and save completed files externally. Up to 10 retained jobs/20 items each are supported; queue storage is separate from project backups. Back up all parts must all be saved and restored separately.
